# Robo Brand Architecture

This directory contains the definitive brand guidelines for the Robo ecosystem. These documents serve as the source of truth for AI agents and human developers working on any user-facing aspects of the platform.

## Philosophy

Robo's brand identity combines:

- **Cyberpunk/Tron aesthetic** meets approachable functionality
- **Sharp, edgy visual identity** with zero rounded corners (Exa Design)
- **Dark-first, futuristic** experience that doesn't overwhelm
- **Tiered voice system** with game/anime-inspired personas

## Platform Definitions

| Platform     | Description                                                                 |
| ------------ | --------------------------------------------------------------------------- |
| **RoboKit**  | Development platform for building Discord bots and Robo.js projects         |
| **RoboPlay** | Hosting platform and API that powers deployments and backend services       |

## Brand Pillars

1. **Sharp Geometry (Exa Design)** - No rounded corners, SVG-driven angular shapes
2. **Voice Hierarchy** - Raphael (UI) → Great Sage (AI)

## Quick Reference

### Capitalization Rules

Always capitalize these terms:

- **Robo** - User's bot/project
- **Sage** / **Great Sage** / **Raphael** - AI personas

### Visual Rules

- No rounded corners anywhere (use slope parameter)
- Dark theme first
- Red text = destructive actions only
- Diamond badge = external links only

### Voice Rules

- **Raphael** (UI): Direct, efficient, contractions OK
- **Great Sage** (AI): Formal, analytical, asterisks for narration

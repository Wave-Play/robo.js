# Terminology Guide

This document defines capitalization rules, glossary of terms, and user-facing vocabulary for the Robo ecosystem.

> **Related**: For visual design patterns, see [exa-design.md](exa-design.md). For UX copy patterns, see [ux-copy.md](ux-copy.md).

---

## Capitalization Rules

### Always Capitalized

These terms are **always capitalized** regardless of position in sentence:

| Term           | Usage                          | Example                     |
| -------------- | ------------------------------ | --------------------------- |
| **Robo**       | User's bot/project             | "Deploy your Robo"          |
| **Sage**       | AI companion (base form)       | "Ask Sage for help"         |
| **Great Sage** | AI companion (analytical form) | "Great Sage analyzing..."   |
| **Raphael**    | AI companion (advanced form)   | "Raphael mode activated"    |

### Title Case (Proper Nouns)

| Term       | Context                          |
| ---------- | -------------------------------- |
| RoboPlay   | Hosting platform and API         |
| RoboKit    | Development platform             |
| Exa Design | Visual design system             |
| WavePlay   | Parent company                   |

### Lowercase

| Term       | Context                   |
| ---------- | ------------------------- |
| deployment | Generic deployment action |

## Glossary

### Core Terms

**Robo**

- User's Discord bot or Robo.js project
- Has associated files, commands, settings
- User-facing: "Create a Robo", "Deploy your Robo"

### Platforms

**RoboKit**

- Development platform for building Discord Apps and Robo.js projects
- User-facing: "Build in RoboKit"

**RoboPlay**

- Hosting platform and API backend
- User-facing: "Hosted on RoboPlay"

**WavePlay**

- Parent company of the Robo ecosystem

### AI Personas

**Sage**

- Default AI companion
- Lightweight, fast model tier
- Helpful, terse responses

**Great Sage**

- Analytical AI persona
- Game/anime-inspired voice
- Formal, precise, uses asterisk narration
- Female persona
- Default voice for AI agents

**Raphael**

- Advanced AI form
- More natural, conversational
- "Robot trying to sound human"
- Uses contractions, feels more approachable

## Writing Guidelines

### 1. Consistent Capitalization

Always capitalize brand terms even mid-sentence:

- ✓ "Deploy your Robo"
- ✗ "Deploy your robo"
- ✓ "Ask Sage for help"
- ✗ "Ask sage for help"

### 2. No Forced Whimsy

Game-inspired terminology should enhance, not confuse:

- ✓ Clear, direct language
- ✗ Overly elaborate fantasy language

### 3. Context Matters

Adapt phrasing to context while maintaining brand voice.

---

## Term Evolution

As the platform evolves, new terms may be added. When adding terms:

1. Define capitalization rule
2. Add to glossary with clear explanation
3. Specify user-facing vs internal usage
4. Update this document immediately

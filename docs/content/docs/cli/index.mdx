Create professional command-line applications with minimal boilerplate. Define commands as files, and `@robojs/cli` generates a standalone executable during `robo build`. Full TypeScript inference, automatic help generation, subcommand nesting, and extensible hooks come out of the box.

## Features

<FeatureGrid>
	<Feature icon={<FileText />} title="File-based Routing" description="Commands map directly to files in your project" />
	<Feature icon={<Shield />} title="Type-safe Options" description="Full TypeScript inference for command options" />
	<Feature icon={<Boxes />} title="Subcommands" description="Nested directories become subcommands automatically" />
	<Feature icon={<BookText />} title="Auto Help" description="Help text generated from your config" />
	<Feature icon={<Zap />} title="Zero Config" description="Works out of the box with sensible defaults" />
</FeatureGrid>

## Installation

Add to your existing Robo.js project:

```bash
npx robo add @robojs/cli
```

Or scaffold a new project with the plugin:

```package-install
npx create-robo my-cli -p @robojs/cli
```

## Quick start

<Steps>
	<Step>
		### Create a command

		<Files>
			<Folder name="src" defaultOpen disabled>
				<Folder name="cli" defaultOpen disabled>
					<File name="hello.ts" />
				</Folder>
			</Folder>
		</Files>

		<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
			<Tab value="TypeScript">
				```ts title="src/cli/hello.ts"
				import { createCliCommandConfig, type CliContext } from 'robo.js/cli.js'

				export const config = createCliCommandConfig({
					description: 'Say hello to someone',
					options: [
						{ alias: '-n', name: '--name', description: 'Name to greet', type: 'string', default: 'World' }
					]
				} as const)

				export default (ctx: CliContext<typeof config>) => {
					console.log(`Hello, ${ctx.options.name}!`)
				}
				```
			</Tab>
			<Tab value="JavaScript">
				```js title="src/cli/hello.js"
				export const config = {
					description: 'Say hello to someone',
					options: [
						{ alias: '-n', name: '--name', description: 'Name to greet', type: 'string', default: 'World' }
					]
				}

				export default (ctx) => {
					console.log(`Hello, ${ctx.options.name}!`)
				}
				```
			</Tab>
		</Tabs>
	</Step>
	<Step>
		### Build and link

		```bash
		npx robo build
		npm link
		```

		The `bin` field is automatically added to `package.json` during build, and `npm link` makes your CLI available by name.
	</Step>
	<Step>
		### Run

		```bash
		my-cli hello
		# Hello, World!

		my-cli hello --name Robo
		# Hello, Robo!
		```

		<Callout type="info">
		During `robo dev`, you can also use `/cli link` in the interactive terminal or `/cli run` to test commands inline. See the [Development](./development) guide for more.
		</Callout>
	</Step>
</Steps>

## Functions

### `t()`

Formats a localized message by key. Parameters are optional and their types are inferred from the MF2 message syntax.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  function t<K extends LocaleKey>(
  	locale: LocaleLike,
  	key: K,
  	params?: ParamsFor<K>
  ): ReturnOf<K>
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  function t(
  	locale: LocaleLike,
  	key: K,
  	params?: ParamsFor<K>
  ): ReturnOf<K>
  ```

</Tab>
</Tabs>

<TypeTable
	type={{
		locale: { type: 'LocaleLike', description: 'Locale string, { locale } object, { guildLocale } object, or Discord Interaction.' },
		key: { type: 'LocaleKey', description: 'Namespaced translation key (e.g., "app:hello").' },
		params: { type: 'ParamsFor<K>', description: 'Optional parameters. Types inferred from MF2 annotations.' },
	}}
/>

Returns `string` for scalar keys, `string[]` for array keys.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  t('en-US', 'app:hello', { name: 'Robo' })           // "Hello Robo!"
  t('en-US', 'app:pets.count', { count: 3 })           // "You have 3 pets"
  t(interaction, 'app:hello', { name: 'Robo' })        // uses interaction.locale
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  t('en-US', 'app:hello', { name: 'Robo' })           // "Hello Robo!"
  t('en-US', 'app:pets.count', { count: 3 })           // "You have 3 pets"
  t(interaction, 'app:hello', { name: 'Robo' })        // uses interaction.locale
  ```

</Tab>
</Tabs>

Throws if locales aren't loaded, the locale doesn't exist, or the key is missing. See [error reference](./configuration.mdx#error-reference) for details.

### `tr()`

Strict variant of `t()`. When a key has parameters, all are required and non-undefined.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts

  	locale: LocaleLike,
  	key: K,
  	...args: MaybeArgs<K>
  ): ReturnOf<K>
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  function tr(
  	locale: LocaleLike,
  	key: K,
  	...args: MaybeArgs<K>
  ): ReturnOf<K>
  ```

</Tab>
</Tabs>

<TypeTable
	type={{
		locale: { type: 'LocaleLike', description: 'Locale string or object.' },
		key: { type: 'LocaleKey', description: 'Namespaced translation key.' },
		args: { type: 'MaybeArgs<K>', description: "Required params object when key has parameters, nothing when it doesn't." },
	}}
/>

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">


### `withLocale()`

Creates a curried translator bound to a specific locale. Supports loose and strict modes.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  // Loose mode (default)
  function withLocale(locale: LocaleLike): <K extends LocaleKey>(
  	key: K,
  	params?: ParamsFor<K>
  ) => ReturnOf<K>

  // Strict mode
  function withLocale(locale: LocaleLike, opts: { strict: true }): <K extends LocaleKey>(
  	key: K,
  	...args: MaybeArgs<K>
  ) => ReturnOf<K>
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  // Loose mode (default)
  function withLocale(locale): <K extends LocaleKey>(
  	key: K,
  	params?: ParamsFor<K>
  ) => ReturnOf<K>

  // Strict mode
  function withLocale(locale, opts): <K extends LocaleKey>(
  	key: K,
  	...args: MaybeArgs<K>
  ) => ReturnOf<K>
  ```

</Tab>
</Tabs>

<TypeTable
	type={{
		locale: { type: 'LocaleLike', description: 'Locale to bind the translator to.' },
		opts: { type: '{ strict?: boolean }', description: 'Pass { strict: true } for strict parameter enforcement.', default: 'undefined' },
	}}
/>

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  const t$ = withLocale(interaction)
  t$('app:hello', { name: 'Robo' })

  const tr$ = withLocale('en-US', { strict: true })
  tr$('app:hello', { name: 'Robo' })  // params required
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  const t$ = withLocale(interaction)
  t$('app:hello', { name: 'Robo' })

  const tr$ = withLocale('en-US', { strict: true })
  tr$('app:hello', { name: 'Robo' })  // params required
  ```

</Tab>
</Tabs>

### `loadLocales()`

Scans `/locales/**/*.json`, builds namespaced keys, stores data in Robo.js State, and generates TypeScript types. Returns elapsed time in milliseconds.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  function loadLocales(): number
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  function loadLocales(): number
  ```

</Tab>
</Tabs>

This runs automatically via the `start` lifecycle hook (`src/robo/start.ts`). Call it manually for testing or non-Robo environments.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  import { loadLocales } from '@robojs/i18n'

  const ms = loadLocales()
  console.log(`Loaded in ${ms}ms`)
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  import { loadLocales } from '@robojs/i18n'

  const ms = loadLocales()
  console.log(`Loaded in ${ms}ms`)
  ```

</Tab>
</Tabs>

### `ParamsFor<K>`

Maps a `LocaleKey` to its parameter type object. All fields are optional.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  type ParamsFor<K extends LocaleKey> = LocaleParamsMap[K]

  // Example resolved types:
  ParamsFor<'app:hello'>        // { name?: string }
  ParamsFor<'app:pets.count'>   // { count?: number }
  ParamsFor<'app:event'>        // { ts?: Date | number }
  ParamsFor<'app:profile'>      // { user?: { name?: string }, stats?: { count?: number } }
  ```

</Tab>
<Tab value="JavaScript">

  ```js

  // Example resolved types:
  ParamsFor<'app:hello'>        // { name?: string }
  ParamsFor<'app:pets.count'>   // { count?: number }
  ParamsFor<'app:event'>        // { ts?: Date | number }
  ParamsFor<'app:profile'>      // { user?: { name?: string }, stats?: { count?: number } }
  ```

</Tab>
</Tabs>

### `StrictParamsFor<K>`

Deep-required version of `ParamsFor<K>`. All fields become required and non-nullable, recursively. Used internally by `tr()`.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  type StrictParamsFor<K extends LocaleKey> = DeepRequired<ParamsFor<K>>

  // Example:
  StrictParamsFor<'app:hello'>   // { name: string }
  StrictParamsFor<'app:profile'> // { user: { name: string }, stats: { count: number } }
  ```

</Tab>
<Tab value="JavaScript">

  ```js

  // Example:
  StrictParamsFor<'app:hello'>   // { name: string }
  StrictParamsFor<'app:profile'> // { user: { name: string }, stats: { count: number } }
  ```

</Tab>
</Tabs>

### `MaybeArgs<K>`

Conditional tuple type used by `tr()`. Resolves to `[StrictParamsFor<K>]` when the key has parameters, or `[]` when it doesn't.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  type MaybeArgs<K extends LocaleKey> = keyof ParamsFor<K> extends never
  	? []
  	: [StrictParamsFor<K>]
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  	? []
  	: [StrictParamsFor<K>]
  ```

</Tab>
</Tabs>

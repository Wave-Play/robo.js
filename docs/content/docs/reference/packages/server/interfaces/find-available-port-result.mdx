# Interface: FindAvailablePortResult

Result of finding an available port

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="originalport"></a> `originalPort` | `number` | Original port that was requested |
| <a id="port"></a> `port` | `number` | The available port that was found |
| <a id="wasincremented"></a> `wasIncremented` | `boolean` | Whether the port was incremented from the original |

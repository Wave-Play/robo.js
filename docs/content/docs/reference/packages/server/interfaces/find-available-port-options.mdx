# Interface: FindAvailablePortOptions

Options for finding an available port

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="hostname"></a> `hostname?` | `string` | Hostname to check (defaults to 'localhost') |
| <a id="maxattempts"></a> `maxAttempts?` | `number` | Maximum number of ports to try (defaults to 10) |
| <a id="port"></a> `port` | `number` | Starting port number |

# Interface: TunnelProvider

Interface for tunnel providers.
Implement this to add support for new tunnel services.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="name"></a> `name` | `string` | Provider name (e.g., 'cloudflare', 'ngrok') |

# Interface: ResolvedPluginRoute

Resolved plugin route configuration with normalized prefixes and asset info.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="apiprefix"></a> `apiPrefix` | `string` | API route prefix (null if no prefix) |
| <a id="exclusive"></a> `exclusive` | `boolean` | Whether routes are exclusive to the prefix (default: true) |
| <a id="name"></a> `name` | `string` | Plugin package name |
| <a id="publicdir"></a> `publicDir` | `string` | Path to plugin's public directory (null if none exists) |
| <a id="staticprefix"></a> `staticPrefix` | `string` | Static asset prefix (null if no prefix) |

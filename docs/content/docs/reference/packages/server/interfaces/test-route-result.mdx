# Interface: TestRouteResult

Result type for route testing that includes both Response and convenience methods

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="ok"></a> `ok` | `boolean` | Whether response status is 2xx |
| <a id="response"></a> `response` | `Response` | The raw Response object |
| <a id="status"></a> `status` | `number` | Response status code |

# Interface: TunnelProviderConfig

Configuration for tunnel providers.
Contains provider-specific settings.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="accountid"></a> `accountId?` | `string` | - |
| <a id="apikey"></a> `apiKey?` | `string` | - |
| <a id="detached"></a> `detached?` | `boolean` | Run tunnel process in detached mode (for background operation) |
| <a id="domain"></a> `domain?` | `string` | Cloudflare-specific configuration |
| <a id="timeout"></a> `timeout?` | `number` | Timeout in ms for waiting for tunnel URL (default: 30000) |
| <a id="tunnelid"></a> `tunnelId?` | `string` | - |
| <a id="tunneltoken"></a> `tunnelToken?` | `string` | - |
| <a id="zoneid"></a> `zoneId?` | `string` | - |

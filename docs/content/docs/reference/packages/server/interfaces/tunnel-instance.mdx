# Interface: TunnelInstance

Represents a running tunnel instance.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="process"></a> `process` | `ChildProcess` | The tunnel process |
| <a id="provider"></a> `provider` | `string` | The provider that created this instance |
| <a id="url"></a> `url?` | `string` | The public tunnel URL (if available) |

# @robojs/server

API reference documentation for `@robojs/server`.

## Classes

- [`CloudflareProvider`](classes/cloudflare-provider) - Cloudflare Tunnel Provider implementation.
- [`RoboRequest`](classes/robo-request) - Extends the [Web Request API](https://developer.mozilla.org/docs/Web/API/Request) with additional convenience methods.
- [`RoboResponse`](classes/robo-response) - Extends the [Web Response API](https://developer.mozilla.org/docs/Web/API/Response) with additional convenience methods.

## Functions

- [`CreateTestClient`](functions/create-test-client) - Creates a fluent test client for testing multiple routes.
- [`CreateTestRequest`](functions/create-test-request) - Creates a RoboRequest suitable for testing API handlers.
- [`Define`](functions/define) - Define a typed API endpoint with optional Zod schema.
- [`FindAvailablePort`](functions/find-available-port) - Find an available port, starting from the given port and incrementing if necessary.
- [`GetPluginRouteRegistry`](functions/get-plugin-route-registry) - Get the global plugin route registry.
- [`GetServerEngine`](functions/get-server-engine)
- [`InitPluginRoutes`](functions/init-plugin-routes) - Initialize the plugin route registry with prefix configuration.
- [`IsPortAvailable`](functions/is-port-available) - Check if a specific port is available on the given hostname.
- [`Ready`](functions/ready) - Returns a promise that resolves when the plugin is all set up.
- [`TestHandler`](functions/test-handler) - Tests a specific handler function directly without method dispatch.
- [`TestRoute`](functions/test-route) - Tests an API route module by dispatching to the appropriate handler.

# Interface: SetStateOptions

Options for setState calls.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="optimistic"></a> `optimistic?` | `boolean` | Apply update optimistically (instant local update, rollback on failure) |
| <a id="throttle"></a> `throttle?` | `number` | Override throttle for this specific call (ms) |

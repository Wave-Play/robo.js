# Type Alias: RoadmapCard

```ts
type RoadmapCard = {
  assignees: {
     avatarUrl: string;
     id: string;
     name: string;
    }[];
  column: string;
  description: string;
  id: string;
  labels: string[];
  metadata: Record<string, unknown>;
  title: string;
  updatedAt: Date;
  url: string;
};
```

Represents a unit of work surfaced by the roadmap.

## Type declaration

| Name | Type | Description |
| ------ | ------ | ------ |
| <a id="assignees"></a> `assignees` | \{ `avatarUrl`: `string`; `id`: `string`; `name`: `string`; \}[] | Contributors actively working on the card. |
| <a id="column"></a> `column` | `string` | Identifier of the column or status the card currently resides in. |
| <a id="description"></a> `description` | `string` | Rich description used when posting updates or expanding a card. |
| <a id="id"></a> `id` | `string` | Unique identifier assigned by the provider (e.g., Jira issue key). |
| <a id="labels"></a> `labels` | `string`[] | Labels associated with the card; maps to Discord forum tags where applicable. |
| <a id="metadata"></a> `metadata`? | `Record`\<`string`, `unknown`\> | Provider specific metadata that does not have a dedicated field. May be omitted when not needed by the provider. |
| <a id="title"></a> `title` | `string` | Concise title or summary displayed to Discord users. |
| <a id="updatedat"></a> `updatedAt` | `Date` | Timestamp representing the last modification time in the provider. |
| <a id="url"></a> `url` | `string` | Deep link to the provider for additional context. |

## Remarks

Each card mirrors an entity fetched from the external provider (issue, ticket, card, etc.). The
metadata is designed to support Discord specific rendering while preserving provider identifiers
for bidirectional navigation.

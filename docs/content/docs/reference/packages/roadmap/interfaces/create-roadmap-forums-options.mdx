# Interface: CreateRoadmapForumsOptions

Options for creating roadmap category and forum channels.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="columns"></a> `columns` | [`RoadmapColumn`](../type-aliases/roadmap-column)[] | Array of columns from the provider to create forums for. Each column will get its own dedicated forum channel. |
| <a id="guild"></a> `guild` | `Guild` | The Discord guild where the category and forums will be created. |

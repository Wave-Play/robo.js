# @robojs/discordjs

API reference documentation for `@robojs/discordjs`.

## Interfaces

- [`AggregatedPermissions`](interfaces/aggregated-permissions) - Aggregated permission information for a command.
- [`BaseConfig`](interfaces/base-config) - Base configuration shared by all handler types.
- [`CommandConfig`](interfaces/command-config) - Command configuration options.
- [`CommandController`](interfaces/command-controller) - Command controller for portal.discordjs.command().
- [`CommandDefaults`](interfaces/command-defaults) - Default command/context menu configuration.
- [`CommandEntry`](interfaces/command-entry) - Command entry in manifest (includes subcommands).
- [`Command`](interfaces/command) - Command module structure expected in handler files.
- [`CommandsNamespaceController`](interfaces/commands-namespace-controller) - Namespace controller for portal.discord.commands.
- [`ContextConfig`](interfaces/context-config) - Context menu configuration options.
- [`ContextController`](interfaces/context-controller) - Context menu controller for portal.discordjs.context().
- [`ContextNamespaceController`](interfaces/context-namespace-controller) - Namespace controller for portal.discordjs.context.
- [`Context`](interfaces/context) - Context menu module structure expected in handler files.
- [`DiscordConfig`](interfaces/discord-config) - Discord plugin configuration.
- [`DiscordPortalNamespace`](interfaces/discord-portal-namespace) - Discord namespace on the portal.
- [`DiscordjsAggregatedMetadata`](interfaces/discordjs-aggregated-metadata) - Aggregated Discord metadata with full traceability.
- [`EventConfig`](interfaces/event-config) - Event configuration options.
- [`EventController`](interfaces/event-controller) - Event controller for portal.discord.event().
- [`Event`](interfaces/event) - Event module structure expected in handler files.
- [`EventsNamespaceController`](interfaces/events-namespace-controller) - Namespace controller for portal.discord.events.
- [`MiddlewareChainEntry`](interfaces/middleware-chain-entry) - Middleware chain entry with handler and metadata.
- [`MiddlewareConfig`](interfaces/middleware-config) - Middleware configuration options.
- [`MiddlewareController`](interfaces/middleware-controller) - Middleware controller for portal.discord.middleware().
- [`MiddlewareData`](interfaces/middleware-data) - Middleware data passed to handler.
- [`MiddlewareNamespaceController`](interfaces/middleware-namespace-controller) - Namespace controller for portal.discord.middleware.
- [`MiddlewareResult`](interfaces/middleware-result) - Middleware result that can abort or modify processing.
- [`Middleware`](interfaces/middleware) - Middleware module structure expected in handler files.
- [`PluginState`](interfaces/plugin-state) - Plugin state interface for internal storage.
- [`RegisterCommandsOptions`](interfaces/register-commands-options) - Options for command registration.
- [`RetryEntry`](interfaces/retry-entry) - Retry tracking entry for telemetry/debugging.
- [`SageOptions`](interfaces/sage-options) - Sage (auto-defer/reply) options for commands and context menus.
- [`TimeoutConfig`](interfaces/timeout-config) - Timeout configuration for various operations.

## Type Aliases

- [`AutocompleteHandler`](type-aliases/autocomplete-handler) - Autocomplete handler function type.

- [`ChoiceValueOf`](type-aliases/choice-value-of) - Extracts the literal `value` type from a single choice entry.
- [`CommandContext`](type-aliases/command-context) - Interaction context types.
- [`CommandHandler`](type-aliases/command-handler) - Command handler function type.
- [`CommandIntegrationType`](type-aliases/command-integration-type) - Integration/installation types.
- [`CommandOptionTypes`](type-aliases/command-option-types) - Map of option type names to their resolved TypeScript types.
- [`CommandOption`](type-aliases/command-option) - Command option with discriminated union for channel type.
- [`CommandOptions`](type-aliases/command-options) - Infer options type from command config.
- [`CommandResult`](type-aliases/command-result) - Command result type (what can be returned from a command).
- [`ContextEntry`](type-aliases/context-entry) - Context menu entry in manifest.
- [`ContextHandler`](type-aliases/context-handler) - Generic context handler (either user or message).
- [`ContextTypeValue`](type-aliases/context-type-value)
- [`DiscordEventName`](type-aliases/discord-event-name) - Discord.js event names.
- [`EnforceConfig`](type-aliases/enforce-config) - Enforces that no extra properties exist beyond CommandConfig.
- [`EnforceContextConfig`](type-aliases/enforce-context-config) - Enforces that no extra properties exist beyond ContextConfig.
- [`EventEntry`](type-aliases/event-entry) - Event entry in manifest.
- [`EventHandler`](type-aliases/event-handler) - Event handler function type.
- [`ExactConfig`](type-aliases/exact-config) - Ensures the config only contains valid CommandConfig properties.
- [`ExactContextConfig`](type-aliases/exact-context-config) - Ensures the config only contains valid ContextConfig properties.
- [`MessageContextHandler`](type-aliases/message-context-handler) - Context menu handler function type (message context).
- [`MiddlewareEntry`](type-aliases/middleware-entry) - Middleware entry in manifest.
- [`MiddlewareHandler`](type-aliases/middleware-handler) - Middleware handler function type.
- [`SmartCommandConfig`](type-aliases/smart-command-config) - Smart command config type that enables TypeScript to infer option types.
- [`SmartContextConfig`](type-aliases/smart-context-config) - Smart context config type that enables TypeScript validation.
- [`TypeNameOfOption`](type-aliases/type-name-of-option) - Gets the discriminant "type name" of an option `K`.
- [`UserContextHandler`](type-aliases/user-context-handler) - Context menu handler function type (user context).
- [`ValueOfOption`](type-aliases/value-of-option) - The final value type for an option `K`.

## Variables

- [`Commands`](variables/commands) - Namespace controller for commands - access all commands, execute programmatically.
- [`ContextType`](variables/context-type) - Discord ApplicationCommandType values for context menus.
- [`Context`](variables/context) - Namespace controller for context menus - access all context menus.
- [`DiscordLogger`](variables/discord-logger) - Plugin-wide logger instance.
- [`Events`](variables/events) - Namespace controller for events - access all events, emit programmatically.
- [`Flashcore_key_command_hash_prefix`](variables/flashcore_key_command_hash_prefix) - Flashcore key prefix for caching command hashes.
- [`Flashcore_key_command_register_error`](variables/flashcore_key_command_register_error) - Flashcore key for tracking command registration errors.
- [`Middleware`](variables/middleware) - Namespace controller for middleware - access middleware chain.
- [`Permission_flags`](variables/permission_flags) - Map of permission names to their bitfield values.
- [`Required_intents`](variables/required_intents) - Mapping of Discord event names to their required gateway intents.

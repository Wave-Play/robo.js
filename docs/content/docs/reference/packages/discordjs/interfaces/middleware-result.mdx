# Interface: MiddlewareResult

Middleware result that can abort or modify processing.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="abort"></a> `abort?` | `boolean` | If true, abort the handler execution |
| <a id="payload"></a> `payload?` | `unknown`[] | Optional modified payload to pass to handler |

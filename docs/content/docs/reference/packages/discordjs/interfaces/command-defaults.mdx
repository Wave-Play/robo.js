# Interface: CommandDefaults

Default command/context menu configuration.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="contexts"></a> `contexts?` | (`"Guild"` \| `"BotDM"` \| `"PrivateChannel"`)[] | Default interaction contexts for commands |
| <a id="defaultmemberpermissions"></a> `defaultMemberPermissions?` | `string` \| `number` \| `bigint` | Default member permissions required for commands |
| <a id="integrationtypes"></a> `integrationTypes?` | (`"GuildInstall"` \| `"UserInstall"`)[] | Default integration types for commands |

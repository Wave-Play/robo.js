# Interface: RegisterCommandsOptions

Options for command registration.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="force"></a> `force?` | `boolean` | Whether to force re-registration of all commands |
| <a id="hasembeddedsdk"></a> `hasEmbeddedSdk?` | `boolean` | Whether the embedded app SDK is installed (for Activities support) |
| <a id="retries"></a> `retries?` | [`RetryEntry`](retry-entry)[] | Array to track retry attempts |
| <a id="timeout"></a> `timeout?` | `number` | Registration timeout in milliseconds |

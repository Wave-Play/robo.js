# Interface: TimeoutConfig

Timeout configuration for various operations.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="autocomplete"></a> `autocomplete?` | `number` | Autocomplete response timeout in milliseconds (default: 3000) |
| <a id="commanddeferral"></a> `commandDeferral?` | `number` | Time before auto-deferring commands in milliseconds (default: 250, set via sage.deferBuffer) |
| <a id="commandregistration"></a> `commandRegistration?` | `number` | Command registration timeout in milliseconds (default: 30000) |

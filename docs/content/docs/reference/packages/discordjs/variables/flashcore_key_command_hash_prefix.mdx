# Variable: FLASHCORE\_KEY\_COMMAND\_HASH\_PREFIX

```ts
const FLASHCORE_KEY_COMMAND_HASH_PREFIX: "robo:discordjs:commandHash:" = 'robo:discordjs:commandHash:';
```

Flashcore key prefix for caching command hashes.
Full key format: `robo:discordjs:commandHash:{scope}` where scope is 'global' or 'guild:\{guildId\}'

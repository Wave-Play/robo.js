# Variable: FLASHCORE\_KEY\_COMMAND\_REGISTER\_ERROR

```ts
const FLASHCORE_KEY_COMMAND_REGISTER_ERROR: "robo:discordjs:commandRegisterError" = 'robo:discordjs:commandRegisterError';
```

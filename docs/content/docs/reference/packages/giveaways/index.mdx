# @robojs/giveaways

API reference documentation for `@robojs/giveaways`.

## Interfaces

- [`Giveaway`](interfaces/giveaway) - Flashcore-backed data model representing a single giveaway lifecycle.
- [`GuildSettings`](interfaces/guild-settings) - Per-guild configuration envelope that customizes giveaway behaviour.

## Functions

- [`GetGuildSettings`](functions/get-guild-settings) - Resolve the persisted giveaway settings for a Discord guild.
- [`SetGuildSettings`](functions/set-guild-settings) - Persist custom giveaway settings for a Discord guild.

# Interface: RoleReward

Role reward configuration

## Example

```ts
{ level: 10, roleId: '1234567890123456789' }
```

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="level"></a> `level` | `number` | Level at which this role is awarded (must be positive integer) |
| <a id="roleid"></a> `roleId` | `string` | Discord role ID (18-19 digit snowflake) |

# Interface: RecalcOptions

Options for recalculating user levels

## Examples

```ts
// Default store
await XP.recalcLevel(guildId, userId) // Uses 'default'
```

```ts
// Custom store
await XP.recalcLevel(guildId, userId, { storeId: 'reputation' })
```

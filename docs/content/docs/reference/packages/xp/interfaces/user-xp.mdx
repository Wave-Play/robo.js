# Interface: UserXP

User XP data stored per guild member

## Example

```ts
{
 *   xp: 1500,
 *   level: 5,
 *   lastAwardedAt: 1704067200000,
 *   messages: 423,
 *   xpMessages: 156
 * }
```

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="lastawardedat"></a> `lastAwardedAt` | `number` | Unix timestamp (ms) of last XP award for cooldown tracking |
| <a id="level"></a> `level` | `number` | Current level (derived from XP using default curve) |
| <a id="messages"></a> `messages` | `number` | Total messages sent in guild text channels (increments after basic validation, before No-XP/cooldown checks) |
| <a id="xp"></a> `xp` | `number` | Total XP accumulated (determines level) |
| <a id="xpmessages"></a> `xpMessages` | `number` | Messages that awarded XP (increments only when XP is actually granted, after all checks pass) |

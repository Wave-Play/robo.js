# Interface: LevelUpEvent

Event emitted when a user levels up

 All fields are read-only event data

## Remarks

The storeId field identifies which data store triggered this event. Role rewards
only process events from the default store to avoid conflicts (e.g., reputation
store shouldn't grant Discord roles).

## Example

```ts
{
 *   guildId: '123456789012345678',
 *   userId: '234567890123456789',
 *   storeId: 'default',
 *   oldLevel: 4,
 *   newLevel: 5,
 *   totalXp: 1550
 * }
```

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="guildid"></a> `guildId` | `readonly` | `string` | Guild where level up occurred |
| <a id="newlevel"></a> `newLevel` | `readonly` | `number` | New level (always \> oldLevel) |
| <a id="oldlevel"></a> `oldLevel` | `readonly` | `number` | Previous level |
| <a id="storeid"></a> `storeId` | `readonly` | `string` | Store identifier that triggered this event |
| <a id="totalxp"></a> `totalXp` | `readonly` | `number` | Total XP after level up |
| <a id="userid"></a> `userId` | `readonly` | `string` | User who leveled up |

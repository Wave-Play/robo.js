# @robojs/xp

API reference documentation for `@robojs/xp`.

## Interfaces

- [`AddXpOptions`](interfaces/add-xp-options) - Options for adding XP to a user.
- [`FlashcoreOptions`](interfaces/flashcore-options) - Options for Flashcore storage layer operations.
- [`GetXpOptions`](interfaces/get-xp-options) - Options for retrieving XP data.
- [`GuildConfig`](interfaces/guild-config) - Per-guild XP system configuration.
- [`LeaderboardEntry`](interfaces/leaderboard-entry) - Leaderboard entry with user rank information.
- [`LevelDownEvent`](interfaces/level-down-event) - Event emitted when a user levels down (XP loss).
- [`LevelProgress`](interfaces/level-progress) - Level progress information from computeLevelFromTotalXp.
- [`LevelUpEvent`](interfaces/level-up-event) - Event emitted when a user levels up.
- [`PluginOptions`](interfaces/plugin-options) - Plugin configuration options for @robojs/xp.
- [`RecalcOptions`](interfaces/recalc-options) - Options for recalculating user levels.
- [`RecalcResult`](interfaces/recalc-result)
- [`RoleReward`](interfaces/role-reward) - Role reward configuration.
- [`StoreOptions`](interfaces/store-options) - Options for specifying which data store to use.
- [`UserXp`](interfaces/user-xp) - User XP data stored per guild member.
- [`XpChangeEvent`](interfaces/xp-change-event) - Event emitted when a user's XP changes (without level change).
- [`XpChangeResult`](interfaces/xp-change-result)
- [`XpRemoveResult`](interfaces/xp-remove-result)
- [`XpSetResult`](interfaces/xp-set-result)

## Type Aliases

- [`GlobalConfig`](type-aliases/global-config) - Global configuration defaults applied to all guilds.
- [`RewardsMode`](type-aliases/rewards-mode) - Role reward mode - determines how multiple role rewards are applied.

## Functions

- [`FormatXp`](functions/format-xp) - Formats XP with commas and custom label.
- [`GetXpLabel`](functions/get-xp-label) - Extracts custom XP label from guild config with fallback to 'XP'.

## Variables

- [`Config`](variables/config) - Configuration management for XP system.
- [`Constants`](variables/constants) - Default configuration constants.
- [`Default_curve_a`](variables/default_curve_a) - Default quadratic curve coefficients.
- [`Default_curve_b`](variables/default_curve_b)
- [`Default_curve_c`](variables/default_curve_c)
- [`Events`](variables/events) - Event system for XP changes and level progression.
- [`Leaderboard`](variables/leaderboard) - Leaderboard API for ranking and leaderboard operations.
- [`Math`](variables/math) - Standard level curve mathematics.
- [`Rewards`](variables/rewards) - Role rewards reconciliation API.
- [`Xp1`](variables/xp-1) - XP manipulation API for programmatic XP management.
- [`Xp`](variables/xp)

# Interface: ConversationInput

Optional conversation metadata supplied when invoking [BaseEngine.chat](../classes/base-engine#chat).

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="id"></a> `id?` | `null` \| `string` | Stable conversation identifier used for threading. |
| <a id="metadata"></a> `metadata?` | `Record`\<`string`, `unknown`\> | Arbitrary metadata persisted alongside conversation state. |

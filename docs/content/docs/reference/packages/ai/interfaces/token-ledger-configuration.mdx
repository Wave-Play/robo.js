# Interface: TokenLedgerConfiguration

Configuration object applied when initializing or reconfiguring the ledger.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="hooks"></a> `hooks?` | [`TokenLedgerHooks`](token-ledger-hooks) | Hook callbacks for reacting to ledger events. |
| <a id="limits"></a> `limits?` | [`TokenLimitConfig`](token-limit-config) | Limit rules to enforce. |

# Interface: EngineSupportedFeatures

Enumerates feature flags describing the optional capabilities an engine exposes.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="vision"></a> `vision` | `boolean` | Signals that the model can consume multimodal inputs such as images. |
| <a id="voice"></a> `voice` | `boolean` | Indicates whether the engine can join and respond within voice sessions. |
| <a id="voicetranscription"></a> `voiceTranscription` | `boolean` | True when the engine can perform speech-to-text transcription. |

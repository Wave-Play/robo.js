# Interface: ChatReply

Represents a reply generated by the chat engine, including optional Discord payloads.

| Property | Type | Description |

| <a id="embeds"></a> `embeds?` | readonly (`APIEmbed` \| `JSONEncodable`\<`APIEmbed`\>)[] | Embed payloads returned with the reply. |
| <a id="files"></a> `files?` | readonly ( \| `BufferResolvable` \| `Stream` \| `JSONEncodable`\<`APIAttachment`\> \| `Attachment` \| `AttachmentBuilder` \| `AttachmentPayload`)[] | File attachments included with the reply. |

| <a id="text"></a> `text?` | `string` | Plain text content for the reply. |

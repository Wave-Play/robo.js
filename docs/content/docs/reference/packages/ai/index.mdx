# @robojs/ai

API reference documentation for `@robojs/ai`.

## Classes

- [`BaseEngine`](classes/base-engine) - Abstract base class to be extended by AI engine implementations.
- [`OpenAiEngine`](classes/open-ai-engine) - Coordinates OpenAI powered chat, tool calling, voice, and media capabilities for Robo.js.
- [`TokenLimitError`](classes/token-limit-error) - Error thrown when a `block` mode limit has been exceeded.

## Interfaces

- [`ChatFunctionCall`](interfaces/chat-function-call) - Invocation payload provided when an engine requests tool execution.
- [`ChatFunctionParameters`](interfaces/chat-function-parameters) - JSON schema snippet describing function parameters accepted by a chat tool.
- [`ChatFunctionProperty`](interfaces/chat-function-property) - Schema fragment representing a property definition within [ChatFunctionParameters](chat-function-parameters).
- [`ChatFunction`](interfaces/chat-function) - Definition describing an available tool or function call that an engine may invoke.
- [`ChatHookContext`](interfaces/chat-hook-context) - Hook function invoked during message orchestration.
- [`ChatMessage`](interfaces/chat-message) - Normalized representation of a chat message exchanged with an engine.
- [`ChatOptions`](interfaces/chat-options) - Options controlling a chat invocation.
- [`ChatReply`](interfaces/chat-reply) - Represents a reply generated by the chat engine, including optional Discord payloads.
- [`ChatResult`](interfaces/chat-result) - Normalized chat response structure returned by engines.
- [`ConversationInput`](interfaces/conversation-input) - Optional conversation metadata supplied when invoking [BaseEngine.chat](../classes/base-engine#chat).
- [`ConversationState`](interfaces/conversation-state) - Snapshot describing an active or previous conversation.
- [`EngineSupportedFeatures`](interfaces/engine-supported-features) - Enumerates feature flags describing the optional capabilities an engine exposes.
- [`GenerateImageOptions`](interfaces/generate-image-options) - Parameters accepted by [BaseEngine.generateImage](../classes/base-engine#generateimage) requests.
- [`GenerateImageResult`](interfaces/generate-image-result) - Result returned by [BaseEngine.generateImage](../classes/base-engine#generateimage).
- [`McpCall`](interfaces/mcp-call)
- [`McpTool`](interfaces/mcp-tool) - Configuration for an MCP (Model Context Protocol) server tool.
- [`OpenAiEngineOptions`](interfaces/open-ai-engine-options)
- [`PluginOptions`](interfaces/plugin-options) - Plugin configuration structure resolved during initialization.
- [`PluginUsageOptions`](interfaces/plugin-usage-options) - Token usage configuration including limit rules and hooks.
- [`ReplyHookContext`](interfaces/reply-hook-context)
- [`TokenLedgerConfiguration`](interfaces/token-ledger-configuration) - Configuration object applied when initializing or reconfiguring the ledger.
- [`TokenLedgerHooks`](interfaces/token-ledger-hooks) - Optional hook callbacks invoked during ledger operations.
- [`TokenLimitBreach`](interfaces/token-limit-breach) - Snapshot describing how a limit was breached.
- [`TokenLimitConfig`](interfaces/token-limit-config) - Token limit configuration keyed by model identifier.
- [`TokenLimitErrorContext`](interfaces/token-limit-error-context) - Context supplied when constructing a [TokenLimitError](../classes/token-limit-error).
- [`TokenLimitRule`](interfaces/token-limit-rule) - Configuration describing a single token limit rule.
- [`TokenLimitState`](interfaces/token-limit-state) - Snapshot describing the real-time state of token limits for a model.
- [`TokenRecordOptions`](interfaces/token-record-options) - Options accepted by [recordUsage](../variables/token-ledger) when logging token consumption.
- [`TokenRecordResult`](interfaces/token-record-result) - Response returned after successfully recording usage.
- [`TokenSummaryQuery`](interfaces/token-summary-query) - Parameters controlling usage summary retrieval.
- [`TokenSummaryResult`](interfaces/token-summary-result) - Result structure produced by [getSummary](../variables/token-ledger).
- [`TokenUsageEntry`](interfaces/token-usage-entry) - Individual token usage record persisted to Flashcore.
- [`TokenWindowTotals`](interfaces/token-window-totals) - Aggregate token counts for a given window.
- [`UsageLimitEvent`](interfaces/usage-limit-event) - Event payload emitted when usage breaches at least one limit.
- [`UsageRecordedEvent`](interfaces/usage-recorded-event) - Event payload describing recorded usage and updated totals.
- [`VoiceChatMetadata`](interfaces/voice-chat-metadata) - Supplemental metadata describing a voice interaction.
- [`VoiceChatOptions`](interfaces/voice-chat-options) - Additional configuration applied when orchestrating a voice-enabled chat.
- [`VoiceChatResult`](interfaces/voice-chat-result) - Voice-specific response envelope accompanying chat results.
- [`VoiceInputFrame`](interfaces/voice-input-frame) - Audio frame delivered to the engine when streaming microphone input.
- [`VoicePlaybackDelta`](interfaces/voice-playback-delta) - Delta describing audio playback data streamed to the caller.
- [`VoiceSessionHandle`](interfaces/voice-session-handle) - Handle returned by [BaseEngine.startVoiceSession](../classes/base-engine#startvoicesession) to control an active session.
- [`VoiceSessionStartOptions`](interfaces/voice-session-start-options) - Configuration structure used when starting a managed voice session.
- [`VoiceTranscriptSegment`](interfaces/voice-transcript-segment) - Transcription segment produced during a voice session.

## Type Aliases

- [`ChatHook`](type-aliases/chat-hook)
- [`ChatMessageContent`](type-aliases/chat-message-content) - Union representing plain text or an array of structured content entries.
- [`HookEvent`](type-aliases/hook-event)
- [`Hook`](type-aliases/hook)
- [`ReplyHook`](type-aliases/reply-hook)

- [`TokenSummaryWindow`](type-aliases/token-summary-window) - Sliding windows used when summarizing token usage.
- [`TokenWindow`](type-aliases/token-window) - Token window identifiers including lifetime totals for aggregate queries.
- [`UsageEventListener`](type-aliases/usage-event-listener) - Listener signature for ledger usage events.
- [`UsageEventName`](type-aliases/usage-event-name) - Usage event identifiers emitted by the ledger.
- [`VoiceEndpointingStrategy`](type-aliases/voice-endpointing-strategy) - Strategy describing how voice endpointing should occur.

## Variables

- [`Ai`](variables/ai) - Primary runtime facade for the Robo AI plugin.
- [`TokenLedger`](variables/token-ledger) - High-level facade exposing token accounting utilities, aggregation helpers, and limit.

# @robojs/i18n

API reference documentation for `@robojs/i18n`.

## Interfaces

- [`PluginConfig`](interfaces/plugin-config) - Plugin options for `@robojs/i18n` (e.g., `defaultLocale`).

## Type Aliases

- [`LocaleLike`](type-aliases/locale-like) - A union describing acceptable inputs that carry a locale (string or objects with `locale`/`guildLocale`).

## Functions

- [`ClearFormatterCache`](functions/clear-formatter-cache) - Clears the in-memory MessageFormat cache (useful for tests and hot reloads).
- [`CreateCommandConfig`](functions/create-command-config) - Creates a **localized** command configuration for Robo.js projects.
- [`LoadLocales`](functions/load-locales) - Loads locale JSONs, builds **slash-namespaced** & flattened keys, stores values in State, and writes generated types.
- [`T`](functions/t) - Formats a localized message by key with **strongly-typed params** inferred from your MF2 message.
- [`Tr`](functions/tr) - `tr` — a **strict** version of `t`:.
- [`WithLocale`](functions/with-locale)

- [`Locale`](variables/locale)

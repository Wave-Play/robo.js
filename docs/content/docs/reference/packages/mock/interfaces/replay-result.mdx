# Interface: ReplayResult

Result of a replay operation

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="actionsreplayed"></a> `actionsReplayed` | `number` | Number of actions that were replayed |
| <a id="duration"></a> `duration` | `number` | Actual duration of replay in ms |
| <a id="success"></a> `success` | `boolean` | Whether replay completed successfully |
| <a id="validation"></a> `validation?` | [`ValidationResult`](validation-result) | Validation results if validation was enabled |

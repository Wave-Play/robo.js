# Interface: StorageStats

Storage statistics for monitoring and debugging.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="count"></a> `count` | `number` | Total number of stored attachments |
| <a id="totalbytes"></a> `totalBytes` | `number` | Total size of all stored attachments in bytes |
| <a id="type"></a> `type` | `string` | Storage backend type identifier |

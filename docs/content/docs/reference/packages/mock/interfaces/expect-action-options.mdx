# Interface: ExpectActionOptions

Options for expectAction helper

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="description"></a> `description` | `string` | Human-readable description of what's being asserted |
| <a id="expected"></a> `expected` | `unknown` | Expected data to match |
| <a id="timeout"></a> `timeout?` | `number` | Timeout in milliseconds (default: 5000) |
| <a id="type"></a> `type` | `string` | Action type to wait for |

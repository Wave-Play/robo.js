# Interface: WaitForActionOptions

Options for waiting for an action

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="filter"></a> `filter?` | (`action`: [`RecordedAction`](recorded-action)) =\> `boolean` | Filter function to match specific actions |
| <a id="timeout"></a> `timeout?` | `number` | Timeout in milliseconds (default: 5000) |
| <a id="type"></a> `type` | `string` | Action type to wait for |

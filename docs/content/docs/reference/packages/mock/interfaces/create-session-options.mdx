# Interface: CreateSessionOptions

Options for creating a new session

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="config"></a> `config?` | [`SessionConfig`](session-config) | - |
| <a id="id"></a> `id?` | `string` | Explicit session ID (if not provided, one is generated) |
| <a id="name"></a> `name?` | `string` | - |
| <a id="token"></a> `token?` | `string` | Explicit token (if not provided, one is generated from the session ID) |
| <a id="ttl"></a> `ttl?` | `number` | - |

# Variable: RoleLimits

```ts
const RoleLimits: {
  MAX_COLOR_VALUE: 16777215;
  MAX_NAME_LENGTH: 100;
  MAX_ROLES_PER_GUILD: 250;
  MIN_NAME_LENGTH: 1;
};
```

Validation constants for roles

## Type declaration

| Name | Type | Default value | Description |
| ------ | ------ | ------ | ------ |
| <a id="max_color_value"></a> `MAX_COLOR_VALUE` | `16777215` | 16777215 | Maximum color value (0xFFFFFF) |
| <a id="max_name_length"></a> `MAX_NAME_LENGTH` | `100` | 100 | Maximum role name length |
| <a id="max_roles_per_guild"></a> `MAX_ROLES_PER_GUILD` | `250` | 250 | Maximum roles per guild |
| <a id="min_name_length"></a> `MIN_NAME_LENGTH` | `1` | 1 | Minimum role name length |

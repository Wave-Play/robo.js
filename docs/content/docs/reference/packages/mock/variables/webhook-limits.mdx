# Variable: WebhookLimits

```ts
const WebhookLimits: {
  MAX_NAME_LENGTH: 80;
  MAX_WEBHOOKS_PER_CHANNEL: 15;
  MIN_NAME_LENGTH: 1;
};
```

Validation constants for webhooks

## Type declaration

| Name | Type | Default value | Description |
| ------ | ------ | ------ | ------ |
| <a id="max_name_length"></a> `MAX_NAME_LENGTH` | `80` | 80 | Maximum webhook name length |
| <a id="max_webhooks_per_channel"></a> `MAX_WEBHOOKS_PER_CHANNEL` | `15` | 15 | Maximum webhooks per channel |
| <a id="min_name_length"></a> `MIN_NAME_LENGTH` | `1` | 1 | Minimum webhook name length |

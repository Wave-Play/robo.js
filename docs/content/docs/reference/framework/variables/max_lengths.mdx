# Variable: MAX\_LENGTHS

```ts
const MAX_LENGTHS: {
  composedKey: 1000;
  recordId: 200;
  uniqueFieldValue: 500;
};
```

Maximum lengths for validation.

## Type declaration

| Name | Type | Default value | Description |
| ------ | ------ | ------ | ------ |
| <a id="composedkey"></a> `composedKey` | `1000` | 1\_000 | Maximum length for composed storage keys. |
| <a id="recordid"></a> `recordId` | `200` | 200 | Maximum length for record IDs. |
| <a id="uniquefieldvalue"></a> `uniqueFieldValue` | `500` | 500 | Maximum length for unique field values before encoding. |

# Variable: DEFAULT\_AUTO\_REPAIR\_CONFIG

```ts
const DEFAULT_AUTO_REPAIR_CONFIG: {
  catalog: false;
  filter: true;
  indexes: true;
  uniqueIndexes: true;
};
```

Default auto-repair configuration.
Catalog is never auto-repaired by default (requires explicit opt-in).

## Type declaration

| Name | Type | Default value |
| ------ | ------ | ------ |
| <a id="catalog"></a> `catalog` | `false` | false |
| <a id="filter"></a> `filter` | `true` | true |
| <a id="indexes"></a> `indexes` | `true` | true |
| <a id="uniqueindexes"></a> `uniqueIndexes` | `true` | true |

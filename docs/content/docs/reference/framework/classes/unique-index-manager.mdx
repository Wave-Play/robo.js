# Class: UniqueIndexManager

Manages unique constraints for a model.

Uses adapter setIfNotExists for race-free constraints when available,
otherwise falls back to check-then-set (embedded mode only).

## Constructors

### new UniqueIndexManager()

```ts
new UniqueIndexManager(adapter): UniqueIndexManager
```

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `adapter` | [`FlashcoreAdapter`](../interfaces/flashcore-adapter)\<`string`, `unknown`\> |

#### Returns

[`UniqueIndexManager`](unique-index-manager)

# Class: TransactionContext

Transaction context implementation.

Provides staging for writes/deletes, read tracking for optimistic locking,
and commit logic for different transaction modes.

## Implements

- [`ITransactionContext`](../interfaces/i-transaction-context)

## Constructors

### new TransactionContext()

```ts
new TransactionContext(
   adapter, 
   resolvedMode, 
   options): TransactionContext
```

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `adapter` | [`FlashcoreAdapter`](../interfaces/flashcore-adapter)\<`string`, `unknown`\> |
| `resolvedMode` | [`ResolvedTransactionMode`](../type-aliases/resolved-transaction-mode) |
| `options` | `Required`\<[`TransactionOptions`](../interfaces/transaction-options)\> |

#### Returns

[`TransactionContext`](transaction-context)

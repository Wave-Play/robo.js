# Class: MigrationRunner

Migration runner class.

Handles:
- Lock acquisition/release
- Pending migration discovery
- Migration execution with status tracking
- Rollback on failure
- Dry-run mode

## Constructors

### new MigrationRunner()

```ts
new MigrationRunner(adapter, options?): MigrationRunner
```

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `adapter` | [`FlashcoreAdapter`](../interfaces/flashcore-adapter)\<`string`, `unknown`\> |
| `options`? | [`MigrationRunnerOptions`](../interfaces/migration-runner-options) |

#### Returns

[`MigrationRunner`](migration-runner)

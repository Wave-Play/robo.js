# Function: getJunctionModelName()

```ts
function getJunctionModelName(modelA, modelB): string
```

Get deterministic junction model name for two models.
Models are sorted alphabetically to ensure consistent naming.

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `modelA` | `string` | First model name |
| `modelB` | `string` | Second model name |

## Returns

`string`

Junction model name

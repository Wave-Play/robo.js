# Function: evaluateWhere()

```ts
function evaluateWhere<T>(record, where): boolean
```

| Type Parameter |
| ------ |
| `T` *extends* `Record`\<`string`, `unknown`\> |

| Parameter | Type | Description |
| ------ | ------ | ------ |

## Returns

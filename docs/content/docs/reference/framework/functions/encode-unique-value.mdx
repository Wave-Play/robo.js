# Function: encodeUniqueValue()

```ts
function encodeUniqueValue(value): string
```

Encode a value for use in unique index keys.

Values are encoded to be safe in key paths while remaining
somewhat readable when possible.

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `value` | `unknown` | The value to encode |

## Returns

`string`

Safe key component

# Function: normalizeNamespace()

```ts
function normalizeNamespace(namespace, separator): string[]
```

Normalize namespace input to an array of strings.

## Parameters

| Parameter | Type | Default value | Description |
| ------ | ------ | ------ | ------ |
| `namespace` | `string` \| `string`[] | `undefined` | String or array namespace |
| `separator` | `string` | `DEFAULT_NAMESPACE_SEPARATOR` | Separator for splitting string namespaces (legacy only) |

## Returns

`string`[]

Array of namespace segments

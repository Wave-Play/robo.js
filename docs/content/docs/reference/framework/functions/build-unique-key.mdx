# Function: buildUniqueKey()

```ts
function buildUniqueKey(
   modelName, 
   field, 
   encodedValue, 
   namespace?): string
```

Build a unique index key.

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `modelName` | `string` | The model name |
| `field` | `string` | The unique field name |
| `encodedValue` | `string` | The encoded field value |
| `namespace`? | `string` | Optional namespace |

## Returns

`string`

Unique index key

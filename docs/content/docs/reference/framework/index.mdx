# Framework

API reference documentation for `robo.js`.

## Classes

- [`AdapterBuilder`](classes/adapter-builder) - Builder for composing adapter wrappers.
- [`AdapterError`](classes/adapter-error) - Thrown when an adapter operation fails.
- [`AdapterWrapper`](classes/adapter-wrapper) - Base class for adapter wrappers.
- [`AsyncMutex`](classes/async-mutex) - Simple async mutex for serializing operations.
- [`CacheAdapter`](classes/cache-adapter) - LRU cache wrapper for adapters.
- [`CatalogLockManager`](classes/catalog-lock-manager) - Lock manager for catalog operations.
- [`Catalog`](classes/catalog) - Catalog class for managing ID -> chunk mappings.
- [`ChunkLockManager`](classes/chunk-lock-manager) - Lock manager for chunk operations.
- [`ChunkManager`](classes/chunk-manager) - Chunk manager for a single model.
- [`CompressionAdapter`](classes/compression-adapter) - Compression wrapper for adapters.
- [`ConnectionError`](classes/connection-error) - Thrown when connection to the storage backend fails after retries are exhausted.
- [`CuckooFilter`](classes/cuckoo-filter) - Cuckoo Filter implementation with 16-bit fingerprints.
- [`DataCorruptionError`](classes/data-corruption-error) - Thrown when data corruption is detected (malformed chunk, catalog mismatch).
- [`EncryptionAdapter`](classes/encryption-adapter) - Encryption wrapper for adapters.
- [`Env`](classes/env) - Sometimes you need to store sensitive information, like API keys, database URLs, or other credentials.
- [`FeatureNotSupportedError`](classes/feature-not-supported-error) - Thrown when a feature is not supported by the current adapter configuration.
- [`Field`](classes/field) - Field builder class with fluent modifiers.
- [`FileAdapter`](classes/file-adapter) - File-based storage adapter using the filesystem.
- [`FlashcoreError`](classes/flashcore-error) - Base error class for all Flashcore errors.
- [`FlashcoreModel`](classes/flashcore-model) - FlashcoreModel class.
- [`FlashcoreSchemaError`](classes/flashcore-schema-error) - Thrown when schema validation fails on startup (breaking schema drift).
- [`IndexPersistenceManager`](classes/index-persistence-manager)
- [`IntegrityChecker`](classes/integrity-checker) - Integrity Checker.
- [`JunctionTableManager`](classes/junction-table-manager) - Junction table manager for many-to-many relationships.
- [`KeyvAdapter`](classes/keyv-adapter) - Keyv adapter for Flashcore.
- [`LegacyFileAdapter`](classes/legacy-file-adapter) - Legacy file adapter for backward compatibility with existing .robo/data stores.
- [`Logger`](classes/logger) - The logger class provides a simple and flexible logging system.
- [`MemoryAdapter`](classes/memory-adapter) - In-memory storage adapter using Map.
- [`MigrationError`](classes/migration-error) - Thrown when a migration fails.
- [`MigrationLockManager`](classes/migration-lock-manager) - Manager for migration lock acquisition and release.
- [`MigrationRegistry`](classes/migration-registry) - Migration registry for discovered migrations.
- [`MigrationRunner`](classes/migration-runner) - Migration runner class.
- [`NotFoundError`](classes/not-found-error) - Thrown when a record is not found (e.g., update/delete on non-existent record).
- [`PluginManager`](classes/plugin-manager) - Plugin Manager - handles plugin lifecycle, middleware, and extensions.
- [`QueryPlanner`](classes/query-planner) - Query Planner.
- [`RecordValidator`](classes/record-validator) - Record validator for schema-based validation.
- [`RelationField`](classes/relation-field) - Relation field builder for model relationships.
- [`RepairEngine`](classes/repair-engine) - Repair Engine.
- [`ResilienceAdapter`](classes/resilience-adapter) - Resilience wrapper for adapters.
- [`SafeKeyEncoder`](classes/safe-key-encoder) - SafeKeyEncoder class for stateful encoding operations.
- [`SafetyError`](classes/safety-error) - Thrown when a safety limit is violated (reserved prefixes, result size limits).
- [`SchemaHistoryManager`](classes/schema-history-manager) - Manager for schema version history.
- [`SchemaMetadataManager`](classes/schema-metadata-manager) - Manager for schema metadata persistence.
- [`SerialTransactionQueue`](classes/serial-transaction-queue) - Serial mode queue for serializing transactions within the process.
- [`SortedIndex`](classes/sorted-index) - SortedIndex implementation using a B+Tree.
- [`State`](classes/state) - States are your Robo's personal memory bank.
- [`StorageExhaustedError`](classes/storage-exhausted-error) - Thrown when storage is exhausted (ENOSPC, quota exceeded).
- [`TransactionConflictError`](classes/transaction-conflict-error) - Thrown when a transaction conflict is detected (optimistic locking failure).
- [`TransactionContext`](classes/transaction-context) - Transaction context implementation.
- [`TypeSerializer`](classes/type-serializer) - Type serializer for storing and retrieving records.
- [`UniqueConstraintError`](classes/unique-constraint-error) - Thrown when a unique constraint is violated.
- [`UniqueIndexManager`](classes/unique-index-manager) - Manages unique constraints for a model.
- [`ValidationError`](classes/validation-error) - Thrown when input validation fails (schema validation, type checking, required fields).
- [`WriteAheadLog`](classes/write-ahead-log) - Write-Ahead Log manager.

# Interface: RangeOptions

Range query options.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="gt"></a> `gt?` | `unknown` | Greater than |
| <a id="gte"></a> `gte?` | `unknown` | Greater than or equal |
| <a id="limit"></a> `limit?` | `number` | Maximum number of results |
| <a id="lt"></a> `lt?` | `unknown` | Less than |
| <a id="lte"></a> `lte?` | `unknown` | Less than or equal |
| <a id="order"></a> `order?` | `"asc"` \| `"desc"` | Order: 'asc' (default) or 'desc' |

# Interface: MigrationRunOptions

Options for running migrations.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="dryrun"></a> `dryRun?` | `boolean` | Show what would be done without applying |
| <a id="forceunlock"></a> `forceUnlock?` | `boolean` | Force release the migration lock if stuck |
| <a id="target"></a> `target?` | `string` | Run up to a specific migration name |

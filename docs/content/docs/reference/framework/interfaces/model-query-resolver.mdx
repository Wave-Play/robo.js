# Interface: ModelQueryResolver

Model-level query resolver for complete control over queries.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="fields"></a> `fields?` | `Record`\<`string`, [`FieldQueryResolver`](field-query-resolver)\> | Field-specific resolvers. |

## Methods

### afterResolve()?

```ts
optional afterResolve(ids, args): string[] | Promise<string[]>
```

Called after default resolution.
Can filter or reorder results.

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `ids` | `string`[] |
| `args` | [`FindManyArgs`](find-many-args)\<\{ `id`: `string`; \}\> |

### resolve()?

```ts
optional resolve(args): string[] | Promise<string[]>
```

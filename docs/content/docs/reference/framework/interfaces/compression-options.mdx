# Interface: CompressionOptions

Options for the compression wrapper.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="level"></a> `level?` | `number` | Compression level (1-9, higher = better compression but slower). Default: 6 |
| <a id="threshold"></a> `threshold?` | `number` | Minimum size in bytes before compression is applied. Values smaller than this are stored uncompressed. Default: 512 |

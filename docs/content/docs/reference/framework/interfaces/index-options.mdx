# Interface: IndexOptions

Options for creating a custom index.

## Indexable

```ts

```

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="field"></a> `field?` | `string` | Field name being indexed. |
| <a id="model"></a> `model?` | `string` | Model name the index belongs to. |

# Interface: AggregatedMetadata

Base interface for aggregated namespace metadata.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="namespace"></a> `namespace` | `string` | Namespace this metadata belongs to |
| <a id="sources"></a> `sources` | `string`[] | Sources that contributed to this metadata |

# Interface: PluginSetupContext\<TState\>

Context passed to plugin setup() function.

## Type Parameters

| Type Parameter | Default type |
| ------ | ------ |
| `TState` | `Record`\<`string`, `unknown`\> |

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="models"></a> `models` | `readonly` | [`ModelInfo`](model-info)[] | Information about all registered models. |
| <a id="state"></a> `state` | `public` | `TState` | Plugin state - persists across middleware calls. Initialized as empty object, can be mutated by plugin. |

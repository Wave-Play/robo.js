## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="getmigrations"></a> `getMigrations?` | () =\> [`RegisteredMigration`](registered-migration)[] | Function to discover registered migrations |
| <a id="getmodelaccessor"></a> `getModelAccessor?` | \<`T`\>(`name`: `string`) =\> [`MigrationModelAccessor`](migration-model-accessor)\<`T`\> | Model accessor factory for migration context |

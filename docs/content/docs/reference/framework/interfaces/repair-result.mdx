# Interface: RepairResult

Result of a repair operation.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="durationms"></a> `durationMs` | `number` | Time taken in milliseconds |
| <a id="repaired"></a> `repaired` | `number` | Number of items repaired |
| <a id="success"></a> `success` | `boolean` | - |
| <a id="unrepaired"></a> `unrepaired` | `string`[] | Items that could not be auto-repaired |
| <a id="warnings"></a> `warnings` | `string`[] | Warnings generated during repair |

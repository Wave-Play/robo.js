# Interface: UniqueChange

Unique constraint change descriptor.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="id"></a> `id` | `string` | The record ID that should own this constraint. |
| <a id="key"></a> `key` | `string` | Full unique constraint key (e.g., _model:user:ux:email:alice@example.com). |

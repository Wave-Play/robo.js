# Interface: CliOptionConfig

Configuration for a CLI option (flag).

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="alias"></a> `alias` | `string` | Short flag (e.g., '-t') |
| <a id="default"></a> `default?` | `unknown` | Default value if not provided |
| <a id="description"></a> `description` | `string` | Description shown in help text |
| <a id="name"></a> `name` | `string` | Long flag (e.g., '--tunnel') |
| <a id="required"></a> `required?` | `boolean` | Whether this option is required |
| <a id="type"></a> `type?` | `"string"` \| `"number"` \| `"boolean"` | Type for validation and parsing |

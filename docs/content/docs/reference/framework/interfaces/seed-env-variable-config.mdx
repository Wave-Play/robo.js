# Interface: SeedEnvVariableConfig

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="description"></a> `description?` | `string` | Explanation shown to users when prompting for this variable. |
| <a id="overwrite"></a> `overwrite?` | `boolean` | Allow overwriting pre-existing keys when seeding. |
| <a id="value"></a> `value?` | `string` | Default value assigned when writing to env files. |

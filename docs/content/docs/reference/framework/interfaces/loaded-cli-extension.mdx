# Interface: LoadedCliExtension

Loaded CLI extension with resolved handlers.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="after"></a> `after?` | [`CliAfterHook`](../type-aliases/cli-after-hook) | After hook function |
| <a id="before"></a> `before?` | [`CliBeforeHook`](../type-aliases/cli-before-hook) | Before hook function |
| <a id="config"></a> `config` | [`CliExtendConfig`](cli-extend-config) | Extension configuration |
| <a id="plugin"></a> `plugin` | `string` | Plugin that provides this extension |

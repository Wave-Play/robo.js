| <a id="config"></a> `config` | [`CliCommandConfig`](cli-command-config) | Command configuration |
| <a id="handler"></a> `handler` | [`CliHandler`](../type-aliases/cli-handler) | Command handler function |
| <a id="plugin"></a> `plugin` | `string` | Plugin that provides this command |

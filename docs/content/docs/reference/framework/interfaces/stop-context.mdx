# Interface: StopContext\<TConfig\>

Context provided to stop hooks.
Runs SEQUENTIALLY: project first → plugins in REVERSE order.

## Extends

- [`StartContext`](start-context)\<`TConfig`\>

## Type Parameters

| Type Parameter | Default type |
| ------ | ------ |
| `TConfig` | `unknown` |

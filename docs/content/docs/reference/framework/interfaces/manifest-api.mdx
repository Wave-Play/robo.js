# Interface: ManifestAPI

The Manifest API singleton interface.
Provides lazy-loaded, type-safe access to manifest data.

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="isinitialized"></a> `isInitialized` | `readonly` | `boolean` | Whether the manifest has been initialized |
| <a id="mode"></a> `mode` | `readonly` | `string` | Current runtime mode (supports custom modes like 'beta', 'staging', etc.) |

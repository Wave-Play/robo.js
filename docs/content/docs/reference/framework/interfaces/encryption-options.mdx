# Interface: EncryptionOptions

Options for the encryption wrapper.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="algorithm"></a> `algorithm?` | `"aes-256-gcm"` \| `"aes-256-cbc"` | Algorithm to use. Default: 'aes-256-gcm' |
| <a id="key"></a> `key` | `string` | Encryption key (required). Should be at least 32 characters for AES-256. |
| <a id="salt"></a> `salt?` | `string` | Salt for key derivation. If not provided, a default salt is used (less secure). Default: 'flashcore-v1-salt' Backward compatibility: when `salt` is omitted, decryption also attempts the legacy default salt ('flashcore-v4-salt') to avoid data loss. |

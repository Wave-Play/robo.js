# Interface: NamespaceRouteDefinitions

Route definitions for a namespace.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="namespace"></a> `namespace` | `string` | Plugin namespace |
| <a id="plugin"></a> `plugin` | `string` | Plugin that provides these routes |
| <a id="routes"></a> `routes` | `Record`\<`string`, [`RouteDefinition`](route-definition)\> | Route definitions by route name |

# Interface: PluginState

Plugin-scoped state storage.
Isolated from other plugins using namespaced keys.

## Methods

### clear()

```ts
clear(): void
```

Clear all plugin state.

#### Returns

`void`

***

### delete()

```ts
delete(key): boolean
```

Delete a key from plugin state.

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `key` | `string` |

#### Returns

`boolean`

***

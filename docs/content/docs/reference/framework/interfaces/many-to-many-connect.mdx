# Interface: ManyToManyConnect

Connect/disconnect operations for manyToMany.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="connect"></a> `connect?` | `string`[] | IDs to connect. |
| <a id="disconnect"></a> `disconnect?` | `string`[] | IDs to disconnect. |
| <a id="set"></a> `set?` | `string`[] | Set to exactly these IDs (replaces existing). |

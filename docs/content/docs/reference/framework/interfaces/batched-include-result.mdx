| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="field"></a> `field` | `string` | Field name that was included. |
| <a id="results"></a> `results` | `Map`\<`string`, `unknown`\> | Map of parent record ID to related record(s). |

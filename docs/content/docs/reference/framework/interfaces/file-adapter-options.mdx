# Interface: FileAdapterOptions

Options for the FileAdapter.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="basedir"></a> `baseDir?` | `string` | Base directory for storage. Default: '.robo/flashcore' |
| <a id="extension"></a> `extension?` | `string` | File extension for stored files. Default: '.json' |
| <a id="pretty"></a> `pretty?` | `boolean` | Pretty-print JSON output. Default: false |
| <a id="sync"></a> `sync?` | `boolean` | Use synchronous operations (for simpler semantics). Default: false (async for better performance) |

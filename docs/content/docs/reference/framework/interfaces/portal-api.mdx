# Interface: PortalAPI

The Portal API interface.
Provides namespace-based access to handlers and controllers.

## Extends

- [`PortalNamespaces`](portal-namespaces)

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="isinitialized"></a> `isInitialized` | `readonly` | `boolean` | Whether the portal has been initialized |
| <a id="mode"></a> `mode` | `readonly` | `string` | Current runtime mode |

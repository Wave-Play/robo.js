Robo.js provides a suite of CLI tools for creating, developing, building, and deploying projects. The **[Robo CLI](./robo)** is built into every project, while **[Create Robo](./create-robo)** scaffolds new projects and plugins. Plugins and projects can also **[extend the CLI](./extending)** with custom commands and hooks.

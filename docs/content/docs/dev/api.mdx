## `DEBUG_MODE`

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>

## `sendDebugError`

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  async function sendDebugError(error: unknown): Promise<boolean>
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  async function sendDebugError(error): Promise<boolean>
  ```

</Tab>
</Tabs>

Sends an error to the configured debug Discord channel as a rich embed with **Dismiss** and **Restart** buttons.

**Parameters:**

<TypeTable
	type={{
		error: {
			type: 'unknown',
			description: 'The error to forward. Uses .stack or .message if an Error instance, otherwise String().'
		}
	}}
/>

**Returns:** `true` if the error was sent successfully, `false` otherwise.

The function returns `false` without throwing in these cases:
- Not in development mode (`DEBUG_MODE` is `false`)
- No debug channel configured (neither config nor env var)
- Discord client not available or not ready
- Channel not found or not a text channel
- Message send fails

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  import { sendDebugError } from '@robojs/dev'

  try {
  	await riskyOperation()
  } catch (error) {
  	const sent = await sendDebugError(error)
  	if (!sent) {
  		console.error('Could not forward error to Discord:', error)
  	}
  }
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  import { sendDebugError } from '@robojs/dev'

  } catch (error) {
  ```

## `handleDebugButton`

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  async function handleDebugButton(interaction: ButtonInteraction): Promise<boolean>
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  async function handleDebugButton(interaction): Promise<boolean>
  ```

</Tab>
</Tabs>

Handles button interactions from debug error embeds. Checks if the button's `customId` starts with `__robo_debug_` and processes it.

**Parameters:**

<TypeTable
	type={{
		interaction: {
			type: 'ButtonInteraction',
			description: 'A Discord.js ButtonInteraction object.'
		}
	}}
/>

**Returns:** `true` if the button was a debug button and was handled, `false` otherwise.

Two actions are supported:
- **Dismiss** (`__robo_debug_dismiss`) — Deletes the error message
- **Restart** (`__robo_debug_restart`) — Replies with "Restarting..." then triggers a process restart

The plugin already registers an `interactionCreate` event handler that calls this function automatically. Use this directly only if you need custom button handling logic.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  import { handleDebugButton } from '@robojs/dev'

  // In a custom interaction handler
  if (interaction.isButton()) {
  	const handled = await handleDebugButton(interaction)
  	if (handled) return
  	// Handle other buttons...
  }
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  import { handleDebugButton } from '@robojs/dev'
  ```

## `printErrorResponse`

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  async function printErrorResponse(
  	error: unknown,
  	interaction: CommandInteraction | Message | ButtonInteraction
  ): Promise<void>
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  async function printErrorResponse(
  	error: unknown,
  	interaction: CommandInteraction | Message | ButtonInteraction
  ): Promise<void>
  ```

</Tab>
</Tabs>

Sends an error as a red embed reply. Handles all interaction states automatically.

**Parameters:**

<TypeTable
	type={{
		error: {
			type: 'unknown',
			description: 'The error to display. Uses .message if an Error instance, otherwise String().'
		},
		interaction: {
			type: 'CommandInteraction | Message | ButtonInteraction',
			description: 'The interaction or message to reply to.'
		}
	}}
/>

The function determines the best reply method based on the interaction state:

| State | Method |
|---|---|
| `Message` object | `message.reply()` |
| Deferred interaction | `editReply()` |
| Already replied | `followUp()` (ephemeral) |
| Fresh interaction | `reply()` (ephemeral) |

Error messages are truncated to 4000 characters for Discord embed limits.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```ts
  import { printErrorResponse } from '@robojs/dev'

  export default async function (interaction) {
  	try {
  		await someOperation()
  	} catch (error) {
  		await printErrorResponse(error, interaction)
  	}
  }
  ```

</Tab>
<Tab value="JavaScript">

  ```js
  import { printErrorResponse } from '@robojs/dev'

  export default async function (interaction) {
  	try {
  		await someOperation()
  	} catch (error) {
  		await printErrorResponse(error, interaction)
  	}
  }
  ```

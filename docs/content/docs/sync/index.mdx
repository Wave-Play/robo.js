Real-time state synchronization across clients using WebSockets. Ideal for multiplayer games, collaborative apps, and live dashboards.

</Tab>

Works like React's `useState`, but syncs state across all clients in real-time via WebSockets. Components sharing the same key array see the same state. No manual socket handling required. Requires `@robojs/server` as a peer dependency.

## Installation

Add the plugin to your Robo project:

```bash
npx robo add @robojs/sync
```

<Callout type="info">
`@robojs/server` is also required. Install it with `npx robo add @robojs/server` if you haven't already.
</Callout>

To scaffold a new project with sync preconfigured:

```package-install
npx create-robo my-project -p @robojs/sync
```

## Setup

Wrap your app with `SyncContextProvider` to establish the WebSocket connection and make sync hooks available.

<Tabs items={["TypeScript", "JavaScript"]} groupId="language" persist>
<Tab value="TypeScript">

  ```tsx title="src/app/App.tsx"
  import { SyncContextProvider } from '@robojs/sync'

  export function App() {
  	return (
  		<SyncContextProvider clientData={{ name: 'Player1' }} loadingScreen={<Loading />}>
  			<Activity />
  		</SyncContextProvider>
  	)
  }
  ```

</Tab>
<Tab value="JavaScript">

  ```jsx title="src/app/App.jsx"
  import { SyncContextProvider } from '@robojs/sync'

  export function App() {
  	return (
  		<SyncContextProvider clientData={{ name: 'Player1' }} loadingScreen={<Loading />}>
  			<Activity />
  		</SyncContextProvider>
  	)
  }
  ```

</Tab>
</Tabs>

| Prop | Description |
|------|-------------|
| `clientData` | Metadata attached to the current client. Other clients see this via `client.data`. |
| `loadingScreen` | Component shown while the WebSocket connection is being established. |

## Scaling beyond sync

For complex multiplayer games that need authoritative server state, matchmaking, reconnection, and deterministic logic, consider [Colyseus](https://colyseus.io/). Model your sync keys as Colyseus rooms and move update logic to server-side room handlers.

**Robo Plugins** let you add features to your **Robo** with one command and integrate seamlessly thanks to the **[Robo File Structure](./framework/core/file-structure)**. What's more, anyone can **[create a plugin](./framework/plugins/create)**.

```package-install
npx robo add @robojs/server
```

## Managing Plugins

Install, remove, or upgrade plugins with the **[Robo CLI](./cli/robo)**:

```bash title="Install"
npx robo add @robojs/ai @robojs/server
```

```bash title="Remove"
npx robo remove @robojs/ai
```

```bash title="Upgrade"
npx robo upgrade
```

Learn more about how plugins integrate with the framework in the **[Plugin System](./framework/plugins)** docs.

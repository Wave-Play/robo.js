**Robo.js** is a powerful framework for building epic **Discord** experiences. Create bots, activities, web servers, and more with a tiny footprint and zero dependencies.

It lets you **[reduce boilerplate](./framework/core/file-structure)**, **[add features instantly](./framework/plugins)**, **[follow best practices](./bots/sage)**, **[deploy with ease](./hosting)**, **[persist data](./framework/core/flashcore)**, **[debug inline](./bots/debugging)**, **[share features](./framework/plugins/create)**, **[manage state](./framework/core/state)**, **[stay organized](./framework/core/modules)**, **[join an ecosystem](./framework/plugins)**, and **[so much more](./framework)**.  All for **[less than 700kB](https://packagephobia.com/result?p=robo.js)**.

Best of all, **[it works with your existing code](./bots/migrate)**. You may even find it **[fun](./bots/sage)**!

## Quick Start

Ready to start your adventure? Try **[Create Robo](./robo-cli/create-robo)** in your terminal:

```package-install
npx create-robo <projectName>
```

This will spawn a new **Robo.js** project ready to use. We call these **Robos**.

## Plugin Power Ups

**[Robo Plugins](./framework/plugins)** are special. They let you add features to your **Robo** with one command.

```package-install
npx robo add @robojs/ai @robojs/server
```

Plugins integrate seamlessly thanks to the **[Robo File Structure](./framework/core/file-structure)**. What's more, anyone can **[create a plugin](./framework/plugins/create)**.
